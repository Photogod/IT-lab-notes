# Lab 02: Kali Linux Virtual Machine

## Setup
- Hypervisor: Oracle VirtualBox
- VM: Kali Linux 2025.3
- Resources: 3072 MB RAM, 2 CPUs
- Snapshot taken: clean-start

## Commands I practiced
- pwd (show current folder)
- ls (list files)
- mkdir (make a folder)
- cd (change folder)
- touch (create an empty file)
- passwd (change a password)

## What I learned
- A snapshot lets me undo mistakes in a VM.
- Default passwords are a security risk, so I changed mine.
