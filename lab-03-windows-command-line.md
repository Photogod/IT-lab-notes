# Lab 03: Windows Command Line

## Linux vs Windows
| Task | Linux | Windows |
|------|-------|---------|
| Show my username | whoami | whoami |
| Show computer name | hostname | hostname |
| Show current folder | pwd | cd |
| List files | ls | dir |
| Make a folder | mkdir | mkdir |
| Show network details | ip a | ipconfig |

## What I found
- My Windows computer name (hostname): DESKTOP-8SHUF34
- This is a default name that Windows picked when it was installed.

## What I learned
- Windows and Linux use different commands for the same jobs.
- pwd = where am I, ls = what is here.
- Real companies name computers with a pattern so IT can track them.
