# Lab 01: My Computer

- CPU: Intel Core i5-7300U @ 2.60GHz
- RAM: 8 GB
- Storage: Samsung SSD (512 GB), 106 GB free
- Virtualization: enabled

## What I found
- RAM was almost full (7.9/8 GB) before I opened anything for labs.
- Google Chrome was the biggest memory user: about 2.5 GB across 30 processes.
- Fix: close Chrome before running virtual machines.
- Disabled Adobe startup items (Acrobat, CCXProcess) to free up memory at boot.

## What I learned
- A process is any running program or background service.
- Task Manager (Ctrl + Shift + Esc) shows what is using memory.
